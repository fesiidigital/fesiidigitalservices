# Fesii Digital Services — One Page

A single-page website for **Fesii Digital Services**, offering Social Media Management, Web Development & Landing Pages, and Automation & Digital Marketing (n8n).

## Files

| File | Purpose |
|---|---|
| `index.html` | Main page — content, meta tags, structured data (SEO/AEO/GEO) |
| `styles.css` | All styling (dark theme, responsive layout) |
| `script.js` | Mobile menu, WhatsApp links, smooth scroll, footer year |
| `robots.txt` | Tells search engines what to crawl + sitemap location |
| `sitemap.xml` | Lists site pages for search engine indexing |
| `llms.txt` | Plain-language summary for AI tools (ChatGPT, Perplexity, etc.) |

## Setup before going live

Replace these placeholders across `index.html`, `robots.txt`, `sitemap.xml`, and `llms.txt`:

- `YOUR-DOMAIN.com` → your real domain
- `YOUR-NUMBER` → your WhatsApp number (international format, no `+` or spaces, e.g. `923001234567`)
- `/assets/og-cover.jpg` → a 1200×630 image for social share previews (upload it to an `assets/` folder)
- `/favicon.ico`, `/favicon.svg`, `/apple-touch-icon.png` → your favicon files

## SEO / AEO / GEO features included

- Optimized title, meta description, canonical URL
- Open Graph + Twitter Card tags for social sharing
- `ProfessionalService` + `OfferCatalog` structured data (JSON-LD)
- `FAQPage` structured data + visible FAQ section (AEO — for Google answer boxes)
- `llms.txt` file (GEO — for AI assistants to understand and recommend the site)
- `robots.txt` + `sitemap.xml` for crawling and indexing
- Semantic heading structure (h1 → h2 → h3)
- Static, crawlable HTML content (not JS-dependent)

## After going live

1. Submit `sitemap.xml` in Google Search Console
2. Set up a Google Business Profile if targeting local clients
3. Share the site from your YouTube channel / social profiles (backlinks)
4. Keep adding content (blog, case studies) — rankings build over weeks/months, not instantly
